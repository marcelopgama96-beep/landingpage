Privacy Policy

Last updated: September 21, 2026

This Privacy Policy explains how MZNCode handles data for the Easy HLS Downloader browser extension.

Purpose of the extension

Easy HLS Downloader detects HLS playlists loaded in the current browser tab and lets users download compatible streams when they have the right to access and save that content.

Data processed locally in the browser

The extension processes the following information locally in the user's browser to provide its core features:

  • HLS playlist URLs and related media segment URLs detected in the current tab.
  • The current tab URL and page title, used to associate detected streams with the tab and suggest file names.
  • Selected quality, preview information, duration, and temporary media data needed to download, merge, or convert compatible streams.
  • A randomly generated local client identifier used for membership and free-limit features.
  • Membership status and recovery code information needed to restore premium access in the browser.

Video content and media segments are processed locally whenever possible. MZNCode does not collect or store the content of downloaded videos.

Data sent to MZNCode servers

The extension may contact MZNCode servers for membership and usage-limit features. These requests may include:

  • The extension's randomly generated client identifier.
  • Membership status checks.
  • Free download quota checks and download claim requests.
  • Recovery code restoration requests.

These requests are used only to validate premium access, restore access when requested by the user, and manage the free download limit.

Payments

Payments are processed by Stripe. MZNCode does not directly collect or store card numbers, bank account numbers, or other payment card details inside the extension. Stripe may receive information necessary to process purchases according to its own privacy policy.

Website and CDN requests

To download a stream, the extension sends network requests to the original website or media CDN that serves the playlist and media segments. Some downloads require standard request headers such as Referer or Origin from the original page. These headers are used only to complete the user-initiated download.

Data sharing

MZNCode does not sell user data. Data may be processed by service providers required to operate the extension, such as hosting infrastructure for membership validation and Stripe for payment processing.

Data retention

Local extension data remains in the user's browser until the user clears extension data or removes the extension. Server-side membership and quota records are retained as needed to provide premium access, restore purchases, prevent abuse, and operate the free-limit system.

User control

Users can remove locally stored extension data by clearing the extension's site data in Chrome or uninstalling the extension. Premium users should keep their recovery code if they want to restore access later.

Security

MZNCode uses HTTPS for server communication related to membership and usage-limit features. The extension is designed to process downloads locally in the browser whenever possible.

Changes to this policy

MZNCode may update this Privacy Policy as the extension evolves. The latest version will be published on this page.
