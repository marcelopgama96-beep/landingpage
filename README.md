# MZNCode Landing Page

Static company landing page for MZNCode.

## Publish with GitHub Pages

1. Open the repository settings on GitHub.
2. Go to **Pages**.
3. In **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/**.
5. Save and wait for GitHub to publish the site.

The public URL should be similar to:

`https://marcelopgama96-beep.github.io/landingpage/`
